COOKORA TIMER - UPDATED VERSION

Files:
- index.html: app structure
- style.css: interface styling and responsive layout
- script.js: timer, presets, recipes, and sound behavior

How to open:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with Live Server.

For phone testing on the same Wi-Fi:
1. Start Live Server in VS Code.
2. Use your computer's local IPv4 address and the Live Server port in your phone browser.
3. Make sure both devices are connected to the same Wi-Fi network.

Notes:
- Timer completion sound is generated by the browser. Press Start first to allow the browser to initialize audio.
- Recipe photos use online image links, so photos need an internet connection. The timer and recipe text work locally.
